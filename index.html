RoboCup Logs

A private-team utility for uploading RoboCup soccer simulation reports and match-log archives to a Google Drive account authorized by its owner.

How it works

A GitHub Actions workflow running on a team-managed runner collects match outputs, compresses them, and uses rclone and Google Drive API authorization to upload the archive to a configured Drive folder.

The account owner chooses whether to authorize access. The uploader can create download links and clean up older matching archives according to workflow settings. See the privacy policy for access, sharing, retention and revocation details.

About this website

This website contains public documentation only. It does not host match archives, receive Google credentials, or provide a sign-in form. The uploader is intended for the operator and their team, not as a public file-storage service.
